# 🚀 Quick Start Guide

## Installation (One-time setup)

```bash
# Navigate to project
cd /workspaces/study-system-app

# Install dependencies
pip install -r requirements.txt
```

## Launch the App

```bash
streamlit run app.py
```

The app will open at: **http://localhost:8501**

---

## Main Pages (3 Tabs)

### 1️⃣ **📝 Tasks**
- Manage your to-do list
- Add, view, edit, delete tasks
- Track task status with visual charts

### 2️⃣ **⏱️ Timer**
- Study timer with multiple subjects
- Pomodoro technique support
- Track study sessions and streaks
- View study history

### 3️⃣ **🧠 Learning**
- Interactive flashcards (6 subjects)
- MCQ practice tests
- Switch between modes
- Auto-save progress
